# Credits and data sources

- **Coastlines:** Natural Earth 10m land (public domain), via the
  `world-atlas` npm package.
- **Elevation:** "Terrain Tiles" open dataset on AWS (Mapzen/Linux
  Foundation terrarium tiles), built from public-domain SRTM, GMTED2010 and
  ETOPO1, and other open sources. See
  https://github.com/tilezen/joerd/blob/master/docs/attribution.md
- **Rivers, mountain ridges, lakes, 1453 coast edits, provinces,
  cultures, populations:** drawn and estimated by hand for this game.
- No data or art from Paradox Interactive or Creative Assembly games is
  used.
